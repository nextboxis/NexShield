# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 6.0.x   | :white_check_mark: |
| < 6.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in NexShield, please report it responsibly:

1. **Do not disclose publicly**: Avoid creating public GitHub issues for sensitive vulnerabilities.
2. **Private Reporting**: Open a private security advisory through the GitHub repository's Security tab or contact maintainers directly.
3. **Response Timeline**: Security issues receive initial triage within 48 hours and remediation within an expedited patch window.
